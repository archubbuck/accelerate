# Accelerate Ai

Model gateways, prompts, structured output, agents and evaluation.

Once published, install with `npm install @accelerate/ai@next`. See the [Accelerate SDK catalog](https://www.npmjs.com/package/@accelerate/sdk) for the other packages.

## Import migration

Use the subpaths below. Update related imports together wherever your app shares class or provider identity.

| Existing import | Preview import |
| --- | --- |

| `@accelerate/ai-core` | `@accelerate/ai/core` |
