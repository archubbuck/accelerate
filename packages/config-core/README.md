# @accelerate/config-core

Framework-neutral, dependency-free config primitives for Accelerate.

Install with `npm install @accelerate/config-core` after publication. The source may precede npm availability.

## Usage

See the exported API in [src/index.ts](src/index.ts). Import only from the package root.

## Development

Run `pnpm --filter @accelerate/config-core build`, `typecheck`, and `test` from the repository root.
