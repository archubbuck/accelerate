# @accelerate/typescript-config

Reusable strict TypeScript presets. Extend `@accelerate/typescript-config/base.json` for applications or `@accelerate/typescript-config/library.json` for published libraries. Install TypeScript separately.

```json
{ "extends": "@accelerate/typescript-config/library.json", "compilerOptions": { "rootDir": "src", "outDir": "dist" } }
```
